# LobotomyVR

![Image](https://github.com/user-attachments/assets/3da88597-eba7-4638-9dcc-ee01b1dad83a)

## 프로젝트 소개

**LobotomyVR**는 인기 인디 게임 *Lobotomy Corporation*을  
VR 환경으로 재해석한 **팬 게임**입니다.

기존 2D 탑다운 시뮬레이션과 달리,  
플레이어가 직접 시설 내부를 이동하며 환상체를 관리하고  
위기 상황을 **VR 특유의 몰입감**으로 경험할 수 있도록 설계했습니다.

환상체마다 고유한 관리 규칙이 존재하며,  
이를 지키지 못할 경우 탈출 사태가 발생합니다.  
플레이어는 에너지 할당량을 채우는 동시에  
직원 피해를 최소화하며 시설을 운영해야 합니다.

---

## 기획 및 제작 의도

기존 VR 공포 게임이  
탐험 또는 탈출 중심의 플레이에 치중되어 있는 반면,

본 프로젝트는  
**경영 시뮬레이션 + 호러**를 결합한 새로운 플레이 경험을 목표로 제작했습니다.

- 환상체 관리 규칙을 직접 수행하는 VR 인터랙션
- 실시간 위기 대응과 전략적 판단의 공존
- 원작의 시스템을 VR 환경에 맞게 재해석

## 주요 기능 (Key Features)

- 관리실 / 환상체 연동 시스템  
  - 관리실과 환상체를 1:1로 연동
  - 환상체 상태 변화에 따른 관리실 반응 처리

- 다양한 환상체  
  - 환상체별 고유 행동 및 관리 규칙 구현
  - 작업 결과에 따라 탈출 여부 결정

- 직원 시스템  
  - 대기 / 전투 / 패닉 / 사망 상태 관리
  - 정신력 및 체력 기반 상태 변화

- 맵 기믹  
  - 중앙실, 복도, 관리실 구조 설계
  - 환상체 탈출 시 자동 문 개방 및 사이렌 연동

- 버튼 / 문 상호작용  
  - VR 포크 인터렉션을 통한 직접 조작
  - 문 개폐 및 시설 제어

- 환상체 도감  
  - 환상체 정보, 작업 규칙 확인 가능
  - 버튼 입력을 통한 페이지 이동

# 기능 구현 상세

## VR 인터랙션 및 이동 시스템

### 핸드 트래킹 기반 텔레포트 / 포크 인터렉션

- 플레이어 손 트래킹을 활용한 텔레포트 이동
- 포크 인터렉션으로 버튼 조작
- 문 개폐 및 시설 제어 가능

---

## 환상체 상호작용 시스템

- 작업 중 환상체 종류에 따라 다른 반응 처리
- 작업 결과에 따라 환상체 탈출 여부 결정
- 탈출한 환상체는 개체별 고유 행동 수행
- 환상체 특성에 따른 다양한 대처 방식 구현

---

## 담당한 부분

### 관리실 / 환상체 시스템

- 관리실 입장 시 환상체에게 플레이어 상태 전달
- 환상체 탈출 시 자동 문 개방 처리
- 제압 성공 시 환상체 상태 초기화 및 관리실 복귀

---

### 환상체 로직

- 관리실 입장 후 작업 완료 전까지 퇴장 제한
- 본능 / 통찰 작업 구현
- 작업 중 및 종료 행동에 따른 결과 분기
- 작업 결과를 중앙 TV에 출력
- 에너지 충전량 계산:
  - (작업 결과 × 환상체 등급)
- 특정 조건에서 환상체 탈출
- 탈출 시 사이렌 작동 및 작업 제한
- 제압 후 일정 시간 뒤 관리실 복귀

### 직원 시스템
